# FORMA STUDIO

Адаптивный лендинг архитектурной и дизайн-студии, сверстанный по макету из Figma. Учебный pet-проект: путь от макета до готовой страницы на Vite.

![Превью главной страницы](images/preview.png)

**Демо:** https://nella-z.github.io/forma_studio/

## Что есть на странице

- Шапка с логотипом, меню, телефоном и первым экраном
- «Our Services»: список из четырёх услуг
- «Our Projects»: слайдер проектов (Swiper)
- «From request to turnkey delivery»: 8 шагов работы с нумерацией на CSS-счётчиках
- «Get a catalog»: форма с email и галерея из 8 фото
- Блок заявки с формой на фоновом изображении
- Футер с навигацией, соцсетями и контактами

## Что реализовано

- Адаптивная вёрстка, desktop-first (брейкпоинты: 1500, 1300, 1090, 820, 740 и 540 px)
- Именование классов по БЭМ
- Off-canvas мобильное меню на JavaScript (бургер, анимация на `transform`)
- Слайдер проектов на Swiper: 1, 2 или 3 слайда в зависимости от ширины экрана, стрелки навигации
- Grid для шапки и галереи, Flexbox для остальных блоков
- Обрезка длинного текста в карточках через `line-clamp`
- Современные форматы изображений (AVIF/WebP с запасным JPG) для первого экрана и блока каталога

## Ограничения

- Формы пока без обработки: это только вёрстка
- Ссылки меню и «more» ведут на `#`

## Стек

HTML5 · CSS3 · JavaScript (vanilla) · Swiper 12 · Vite · GitHub Pages

# FORMA STUDIO

Пет-проект. Верстка лендинга по макету из Figma. Делала для практики.

Стек: HTML, CSS, JS, Vite, Swiper.js.

Особенности:
- Адаптив под все экраны (от десктопа до мобилок).
- Оптимизация изображений через picture и image-set.
- Кастомное мобильное меню и слайдер проектов.
